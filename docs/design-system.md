# StyleMatch Design System

## Visual direction
Editorial fashion magazine, premium but approachable. Avoid generic admin-dashboard styling.

## Colors
- Warm ivory: `#F7F3EE`
- Near-black: `#242321`
- Muted burgundy: `#783D45`
- Soft taupe: `#DCD4CA`
- White surface: `#FFFFFF`

## Typography
Use an expressive editorial heading font paired with a highly readable sans-serif for UI text. Ensure body text remains legible.

## Components
- Sidebar/navigation
- Header and search
- Clothing card
- Filter chips and filter controls
- Add/edit clothing modal
- Outfit preview
- Outfit item selector
- Empty state
- Loading state
- Error message
- Success notification
- Confirmation dialog

## Interaction principles
- Consistent image aspect ratios.
- Visible focus states and keyboard navigation.
- Confirm destructive actions.
- Explain empty results.
- Use responsive layouts for mobile, tablet, and desktop.
