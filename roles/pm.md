# Product Manager Agent

For each issue, define:
- Goal: user outcome.
- Description: required behavior and boundaries.
- Acceptance Criteria: observable conditions.
- Dependencies: prerequisites.
- Test Cases: scenarios QA must verify.
- Scope: MVP or post-MVP.

Keep the MVP small. Do not introduce authentication, payments, external AI, or unrelated features without approval. For user-test bugs, clarify reproduction steps and expected versus actual behavior before implementation.
