# StyleMatch — Brainstorming History

## Date
2026-10-19

## Initial goal
Choose a non-trivial application idea different from the previous Student Planner project.

## Selected idea
StyleMatch — a virtual wardrobe and outfit recommendation application.

## Problem
People may own many clothing items but struggle to organize them and combine them into outfits for different occasions and seasons.

## Proposed solution
A responsive web application to manage a digital wardrobe, filter clothing, create and save outfits, and receive transparent rule-based recommendations.

## Alternatives considered
- FreshLoop: food inventory and waste management.
- RentWise: rental price comparison.
- CareerForge: resume and job application analysis.

## Why StyleMatch
The app is visual and demonstrable, with enough technical depth: CRUD operations, relational data, filtering, recommendation logic, API design, persistence, and testing.

## MVP decisions
- Single-user local MVP without authentication.
- React + TypeScript frontend.
- FastAPI backend.
- OpenAPI API contract.
- SQLAlchemy + SQLite persistence.
- Start with a mock frontend service and develop the backend in stages.
- Use rule-based recommendations; do not claim to use a trained AI model.
